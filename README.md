# Aptlantis Zig

A dark SiYuan theme adapted from the Aptlantis Zig logo palette.

Aptlantis Zig pairs near-black and subtly green-charcoal surfaces with controlled gold, warm amber, teal, and sage accents. The logo palette remains recognizable, but saturation is reserved for active controls, links, focus, selection, graph roles, and syntax rather than ordinary text and every application surface.

## Source Material

- Logo: `apt-zig-refs/apt-zig-logo.png`
- Extracted 16-color palette: `apt-zig-refs/apt-zig-logo-palette.txt`
- JetBrains reference theme: `apt-zig-refs/apt-zig-theme.icls`
- Terminal reference theme: `apt-zig-refs/apt-zig-theme.json`

## Package Files

- `theme.json`: SiYuan package metadata
- `theme.css`: theme variables and common SiYuan surface styling
- `icon.png`: marketplace icon generated from the Aptlantis Zig logo
- `preview.png`: package preview image generated from the logo and palette

Code blocks use SiYuan's native Highlight.js token classes. Prism assets are not required or bundled.
